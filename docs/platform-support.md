# 平台支持与降级策略

## 平台优先级

Creator Clone Lab 是以抖音研究为核心的 Skill。小红书、B 站、快手、微信公众号、网页和本地文件属于扩展覆盖，用于补充跨平台样本或处理用户已有素材。

## 统一采集顺序

所有网页平台都由 Playwright 浏览器自动化 Skill 统一控制。Playwright 负责页面访问、短链跳转、快照、登录检测、交互和网络观察；专用脚本只负责后续媒体或结构化数据提取。

统一执行：

```text
1. 检查 Playwright Skill 或 Playwright CLI 是否可用
2. 用 Playwright 命名会话打开链接并解析跳转
3. 生成页面快照，判断主页还是单条内容
4. 检查可见 DOM、登录状态和网络活动
5. 公开访问不完整时复用已认证的 Playwright 会话
6. 确认未登录后才请用户在 Playwright 可视窗口配合
7. Playwright 确认目标后调用媒体提取、OCR、ASR 和关键帧处理
8. 生成去敏 capture_manifest.json
9. 注册来源并标记理解等级
```

## 抖音

- 抖音是账号研究、作品采集、语音与画面理解、表现分层和创作者蒸馏的主链路。
- Playwright 先解析短链、快照公开页面并观察网络，遇到限制后复用已认证命名会话。
- 没有字幕时必须走 ASR；画面承载信息时必须补 OCR 或视觉理解。
- 仅获取标题、描述和封面时，只能标记为 `metadata-only`。

## 小红书

- `extract_xhs_profile.py` 用于公开主页候选提取。
- `capture_xhs_video_from_debug_browser.py` 用于复用 Chrome 调试会话捕获登录后可见的视频。
- 公开主页可能只暴露标题、点赞、类型和封面，此时不能声称视频已下载或完整理解。

## B 站

- `extract_bili_video.py` 提取视频信息和互动指标。
- `yt-dlp` 遇到 HTTP 412 时，使用 API 兜底并通过 FFmpeg 合并 DASH 视频和音频。
- 字幕不可用时进入统一 ASR 流程。

## 快手与微信公众号

- 快手使用 Playwright 短链解析、页面快照、认证会话和通用媒体理解流程。
- 微信公众号保留原始文章 URL、标题、作者、发布时间、正文、图片和可见指标。
- 大型公众号归档按文章独立注册，确保每条知识都能回到具体来源。

## 平台限制

- 平台页面、接口和风控会变化，Skill 不承诺永久免登录抓取。
- 不保存 Cookie、登录令牌或短期签名媒体 URL。
- 不伪装成平台官方接口。
- 抓取结果应遵守平台条款、创作者版权和用户所在地法律。
